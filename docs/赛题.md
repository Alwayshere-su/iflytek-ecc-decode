# 纠错码解码挑战赛 — 赛题说明

> 本文件整合自原始赛题说明（`纠错码解码挑战赛.md`）与官方教程（`教程.md`），
> 作为比赛的基础参考文档保留。

## 一、赛事背景

随着 5G/6G、卫星通信、深空探测、数据存储等领域的飞速发展，信息的可靠传输已成为数字社会的基石。在信号传输过程中，噪声、干扰和衰减不可避免，纠错码作为保障通信可靠性的核心技术，被广泛应用于从移动通信到闪存控制的各种场景。

传统的纠错码解码算法经过数十年发展已相当成熟，但往往面临性能与复杂度的根本性权衡：高性能解码通常伴随高计算开销，难以满足低延迟、低功耗的现代通信需求。近年来，深度学习技术在解码任务中展现出突破传统算法的潜力，有望以神经网络逼近最优解码边界。

## 二、赛事任务

本赛题提供大量模拟的通信数据，数据基于 **POLAR 码** 生成，参数为 **N=64, K=32**。发送的原始码字经过加性高斯白噪声（AWGN）信道后得到接收信号。参赛者需要设计一个解码算法（鼓励神经网络），从接收信号中尽可能准确地恢复出原始码字。

## 三、数据说明

| 数据类别 | 变量 | 数值格式 | 解释 |
|---|---|---|---|
| 原始码字 | id | Int | 样本唯一编号 |
| | bit_0 ~ bit_63 | Int (0/1) | 原始无噪声的比特信息 |
| 含噪信号 | id | Int | 样本唯一编号 |
| | y_0 ~ y_63 | Float | 信号经过信道传输并加入噪声后的数值 |

- **训练集**：提供 id、y_*、bit_*，总训练样本 **64,000,000**（分 500 个 shard，每 shard 128,000 样本，经 `https://hf-mirror.com/datasets/aprofeta/ecc-dataset` 提供）
- **测试集（公开）**：仅提供 id、y_*，共 100,000 样本，bit_* 由官方隐藏用于 BER 计算
- **本地数据**：`train/` 放置训练 shard（复现用 shard 000/001）；`public_test.zip` 为公开测试集

## 四、评估指标

采用 **比特错误率（BER, Bit Error Rate）**：

```
BER = (错误比特总数) / (测试样本数 N × 码长 n)
```

- N 为测试样本总数，n = 64 为码长
- **BER 越低，解码性能越好**，排行榜按 BER 从低到高排序
- 排行榜取团队历史最优成绩进行排名

## 五、提交要求

1. **文件格式**：CSV，字段必须为 `id, bit_0, bit_1, ..., bit_63`
2. 共 100,000 条数据行（+1 表头行）
3. id 与公开测试集完全一致
4. 所有 bit 只能是整数 0 或 1
5. 无空值和额外列
6. 不需要上传代码、模型或其他附件

### 格式校验代码（提交前必跑）

```python
from zipfile import ZipFile
import pandas as pd

path = "submission.csv"
bits = [f"bit_{i}" for i in range(64)]
submission = pd.read_csv(path)

with ZipFile("public_test.zip") as archive:
    with archive.open("competition_data/test_noisy_y_public.csv") as source:
        test_ids = pd.read_csv(source, usecols=["id"])["id"]

assert len(submission) == 100_000, f"行数错误：{len(submission)}"
assert submission.columns.tolist() == ["id", *bits], "列名或列顺序错误"
assert submission["id"].equals(test_ids), "id 与测试集不一致"
assert submission[bits].isin([0, 1]).all().all(), "存在非 0/1 预测"
assert not submission.isna().any().any(), "文件中存在空值"
print("检查通过，可以提交：", path)
```

## 七、官方 Baseline

官方提供 `baseline.py`（OSD 有序统计译码 + 抽样信道校准）：

```bash
# 1. 小规模调试（100 条测试数据）
python baseline.py --max-rows 100 --output submission_debug.csv
# 预期：hard 0.0546 / raw 0.01253 / calibrated 0.01263

# 2. 生成完整提交
python baseline.py --reuse-calibration --output submission.csv
```

Baseline 原理：
1. 从训练 shard 抽样估计每 bit 在 0/1 条件下的接收均值、噪声方差和先验概率
2. 在留出集选择原始或校准后的 LLR
3. 使用官方 `POLAR_N64_K32` 校验矩阵做二阶有序统计译码（OSD-2）
4. OSD 对每条样本动态构造"最可靠信息基"（MRB），枚举少量低可靠 bit 翻转并选取最大似然合法码字

**Baseline 排行榜 BER ≈ 0.01272**（官方 README 口径）。
