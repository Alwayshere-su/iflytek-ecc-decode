## 阶段 1：OSD 超参调优（排行榜 0.01272 → 0.00724）

来源：`纠错码解码挑战赛-Loop.md`（v2）、`实验日志 #1`。

### 1A. 扫描 list_size（order=2，固定校准 10000 行）

| list_size | 模式数 | Val BER |
|---|---|---|
| 5 | 16 | 0.01606 |
| 8 | 37 | 0.01275 |
| 10 | 56 | 0.01144 |
| 12 | 79 | 0.01044 |
| 15 | 121 | 0.00888 |
| 18 | 172 | 0.00809 |
| 20 | 211 | 0.00734 |
| **25** | 326 | **0.00725** |
| 30 | 466 | 0.00738（过大反而变差） |

**结论**：list_size 越大越好但有地板；25 为最优，30 开始退化。

### 1B. order 扫描

- order=3 vs order=2：改善很小但计算量暴涨（5489 vs 326 模式）
- 最终提交配置：list_size=32, order=2 → **排行榜 0.00724**

### 1C. 失败的尝试（阶段 1 记录）

| 方法 | 结果 | 结论 |
|---|---|---|
| BP（Min-Sum，H 上） | 0.021 | BP 不适合该码的校验矩阵（H 含 degree-1 节点） |
| Multi-Start OSD（LLR 扰动） | 0.0105 | 随机扰动不改变 MRB 排序 |
| MLP 端到端（64→512→1024→512→64） | 0.068 | 12.8 万样本不足以学 GF(2) 约束 |
| SCL 解码 | 失败 | 无法确定信息位/冻结位集合（非标准 Polar 表示） |

## 阶段 2：诊断 — 确认 0.00724 = 码字级 ML 下界

来源：`Loop-v3.md`、`Loop-v4.md`、`EXPERIMENT_FINAL_REPORT.md`、`改进思路1.md`。

### 2A. 代码审计（Loop-v3 阶段 A）— 全部通过

- A1：训练标签全部满足 parity（syndrome = 0）✅
- A2：每坐标 0/1 分布 ~50% ✅
- A3：标签是完整 codeword 不是 message ✅
- A4：三种 LLR（raw/pooled/unequal）排序 Spearman 相关 = 0.999 ✅

### 2B. 候选覆盖实验（核心诊断）

| 配置 | Truth in Candidates | Truth Rank=1 | Oracle BER |
|---|---|---|---|
| OSD L=32, O=2 | 993/1000 (99.3%) | 95.7% | ~0.007 |
| **OSD L=32, O=3** | **1000/1000 (100%)** | 95.2% | **0.000000** |

**核心发现**：order=3 时真实码字 100% 在候选列表中！瓶颈是**排序**（~4.8% 样本排错序），不是搜索空间。

### 2C. 信道度量实验（Loop-v3 阶段 D）

| LLR 模式 | Top-1 | 结论 |
|---|---|---|
| raw y | 95.2% | 基线 |
| Pooled/Unequal Gaussian | 95.2% | 与 raw 完全一致（var0/var1≈1.0） |
| Empirical histogram | 96.8% | 边际改善 |
| Power transform | 无改善 | p=1.0 最优 |

**结论**：AWGN 假设几乎完全正确，五种代价函数（Euclidean/abs_llr/Gaussian/Calibrated/Mahalanobis）等价。

### 2D. 坐标权重学习（改进思路2 的落地）— 过拟合

- 训练对仅 103/2000（5.1%），学后验证准确率 51.6%（远差于 uniform 95.9%）
- 原因：训练对太少、L2 正则不足，模型把 α 全压向 0

### 2E. 残差相关性 — 可忽略

- 最大坐标间相关 0.031，平均 0.0062 → bit-wise 独立假设成立

### 2F. 码结构恢复（Loop-v4）

- ✅ 确认为 (64,32) 线性码（XOR 封闭、秩 32、与 baseline H 同一码）
- ❌ 搜索 720 种 bit 排列 + F/F.T + bit-reversal：**均只有 1/64 行匹配** → 非标准 Polar 置换
- ❌ BP 在正确 H 上精炼 LLR：均更差（degree-1 节点引入噪声）

### 2G. 根因诊断（EXPERIMENT_FINAL_REPORT，2000 样本 OSD order=3）

| 检查项 | 结果 |
|---|---|
| Type A（ML 固有）错误 | **92/92 = 100%**（接收信号欧氏距离确实更接近错误码字） |
| 噪声 | 标准独立 AWGN，σ²≈0.40，Eb/N0≈4.0dB，最大相关 0.0103 |
| 错误 Hamming 距离 | d=8: 63%, d=12: 24%, d=16: 8%, d=20: 5% → **d_min ≤ 8** |
| order-4 vs order-3 | 完全一致（41449 vs 5489 候选，零改善） |
| 端到端 Transformer（3.3M 参数） | val_cw_BER = 0.811 完全失败 |
| Syndrome NN | test_cw_BER = 1.000 完全失败 |

**阶段 2 最终结论**：
```
0.00724 是"逐样本独立、码字级判决"框架下的 ML 下界。
再优化 LLR/校准/代价函数/扩大候选都不可能低于 0.00724。
必须改变判决方式本身。
```

## 阶段 3：bit-MAP 列表译码（排行榜 0.00724 → 0.00692）

来源：`Loop-v5.md`、`提升方案-v6.md`。

### 3A. 关键理论突破：码字级 ML ≠ bit 级 MAP

评估指标是 **bit BER**，不是码字错误率。码字级 ML 最小化码字错误率，
而 **bit 级 MAP（对每个 bit 取后验 P(x_i=1|y) 最大）可以取得更低的 bit BER**：

```
bit-MAP:      x̂_i = argmax_b P(x_i=b|y) = argmax_b Σ_{c∈C, c_i=b} p(y|c)
codeword-ML:  ĉ = argmax_c p(y|c)，再整体输出
```

当错误码字与真实码字在部分 bit 上一致时（weight-8 错误 63%），逐 bit 后验
会把"更可能对的 bit"判对 → bit BER < ML 码字解码。

### 3B. 实现（`bit_map_decoder_fast.py`）

1. OSD order=3（list_size=32）生成 5489 候选/样本（向量化 XOR，24 核并行）
2. 计算每个候选的似然 w_c = exp(-‖y-μ(c)‖²/2σ²)
3. 逐 bit 后验：P(x_i=1|y) = Σ_{c:c_i=1} w_c / Σ_c w_c（log-sum-exp 数值稳定）
4. 输出 x̂_i = 1 当且仅当 P(x_i=1|y) ≥ 0.5

### 3C. 结果

| 方法 | 验证 BER |
|---|---|
| OSD order=3（码字级 ML） | 0.007112 |
| **bit-MAP 列表译码** | **0.006884**（突破码字级 ML 下界） |
| 排行榜（提交 submission_bitmap_v5.csv） | **0.00692** |

## 阶段 4：scale-mixture 似然（排行榜 0.00692 → 0.00675，当前最优）

来源：`突破0.004探索报告.md` 的剩余方向 + `实验日志 #5-#7`。

### 4A. 突破报告的诊断（8 大方向穷尽）

| # | 方向 | 结果 |
|---|---|---|
| 1 | 候选覆盖扩展（GRAND R=16-24/T=3-7 最高 53.6 万模式） | 每样本仅 0.5-0.8 个合法码字，bit 决策零变化 |
| 2 | order-4 vs order-3 | bit 决策仅 7/192000 不同 |
| 3 | 深 GRAND 真 ML 探针 | 从未找到比 OSD top-1 更近的码字 |
| 4 | 覆盖审计（200 万随机码字采样） | OSD 候选捕获 >99.97% 后验质量 |
| 5 | 多 G（不同信息位选择）合并 | bit 决策完全一致 |
| 6 | 信道模型：逐坐标方差均匀、坐标独立、**逐样本 σ² 变化 cv=0.549**、超额峰度 +0.795 | 非高斯性真实但逐坐标修正不足以稳定翻转 |
| 7 | 非高斯修正（KDE/t 分布/经验直方图/f(d²) 学习） | 全部无效 |
| 8 | 逐样本 σ²（oracle 实验） | 完美 σ² 也只能到 0.006719（-0.00018） |

**突破报告结论**：剩余可落地改进仅 0.0003-0.0005（逐样本 σ² + 温度缩放）。

### 4B. scale-mixture 似然（实验 #5，`scale_mixture_test.py`）

**动机**：信道是混合 SNR 的（逐样本 σ² 变化 cv=0.549）。单一全局 σ² 是错误假设。
理论正确的似然是边缘化：

```
p(y|c) = ∫ (2πs²)^(-32) exp(-d²/(2s²)) p(s²) ds²
logw_c = logsumexp_s2 [ -32·log(s2) - d2_c/(2·s2) + log p(s2) ]
```

p(s²) 用全部 128K 训练样本的逐样本残差方差拟合（直方图 200 bins）。

**验证（排行榜同口径 10000 样本）**：

| 方法 | BER |
|---|---|
| 全局 Gaussian | 0.006884 |
| **scale-mixture** | **0.006678（-0.000206）** |

**提交**：`scale_mixture_submit.py --mode infer --output submission_sm.csv`
→ **排行榜 0.00675，排名第 5**。

### 4C. 后续微调穷尽（实验 #6-#7）— 全部无统计意义

| 方向 | 排行榜同口径结果 | 结论 |
|---|---|---|
| 条件化 σ²（|y|² 回归收缩 p(s2)，tau 扫描） | 最优 tau0.8=0.006673 | 比纯 SM 好 8 bit/640000（<0.1σ） |
| 细温度扫描（0.9-1.1） | 最优 1.05=0.006670 | 差 5 bit，<0.1σ |
| 双 shard 拟合 p(s2)（128K×2） | 0.006675 | 与单 shard 差 2 bit |
| LightGBM bit 错误预测 + 翻转 | AUC 0.985 但翻转零改善 | bit-MAP 的 0.5 阈值已是逐 bit 最优 |
| LightGBM 候选重排（2 万样本 top-100） | AUC 0.9966 但 BER +0.000137 变差 | 候选内区分信息已全部在 d2 中 |
| 测试集 SNR 分布检查 | KS p=0.62 与训练集一致 | 无分布偏移可利用 |
| 训练集码字唯一性 | 12.8 万码字去重率 99.997%，测试码字零重合 | kNN/记忆法不可行（2^32 码空间） |

**阶段 4 最终结论**：0.00675 已接近该框架理论极限（oracle σ² 上界 0.006719）。
